## Solving One-Step Equations

An equation is a mathematical statement that two expressions are equal. Solving an equation means finding the value of the variable that makes the statement true. In a one-step equation, you can find that value with a single operation. This is the entry point into algebraic problem-solving.

---

## The Core Principle: Balance

An equation is like a balance scale. Whatever is on the left side equals whatever is on the right side. To solve for the variable, you need to get it alone on one side — but you must keep the scale balanced. Every operation you perform on one side must also be performed on the other side.

This principle is called the **Properties of Equality:**
- **Addition Property:** If a = b, then a + c = b + c.
- **Subtraction Property:** If a = b, then a - c = b - c.
- **Multiplication Property:** If a = b, then a × c = b × c.
- **Division Property:** If a = b, then a ÷ c = b ÷ c (as long as c ≠ 0).

---

## Solving by Addition

Used when a number has been subtracted from the variable.

**Example:** x - 9 = 14

The 9 is being subtracted from x. To undo subtraction, add.
- Add 9 to both sides: x - 9 + 9 = 14 + 9
- Simplify: x = **23**

**Check:** Substitute 23 back into the original equation. 23 - 9 = 14. ✓

Always check your solution. This takes 5 seconds and catches errors immediately.

---

## Solving by Subtraction

Used when a number has been added to the variable.

**Example:** n + 17 = 30

The 17 is being added to n. To undo addition, subtract.
- Subtract 17 from both sides: n + 17 - 17 = 30 - 17
- Simplify: n = **13**

**Check:** 13 + 17 = 30. ✓

---

## Solving by Multiplication

Used when the variable has been divided by a number.

**Example:** y/4 = 7

The y is being divided by 4. To undo division, multiply.
- Multiply both sides by 4: (y/4) × 4 = 7 × 4
- Simplify: y = **28**

**Check:** 28/4 = 7. ✓

---

## Solving by Division

Used when the variable has been multiplied by a number.

**Example:** 6x = 54

The x is being multiplied by 6. To undo multiplication, divide.
- Divide both sides by 6: 6x ÷ 6 = 54 ÷ 6
- Simplify: x = **9**

**Check:** 6(9) = 54. ✓

---

## Equations with Negative Coefficients

**Example:** -3m = 21

Divide both sides by -3:
- m = 21 ÷ (-3)
- m = **-7**

**Check:** -3(-7) = 21. ✓

**Example:** -x = 8

This means -1 × x = 8. Divide both sides by -1:
- x = **-8**

**Check:** -(-8) = 8. ✓

---

## Equations with Fractional Coefficients

**Example:** (2/3)x = 10

To undo multiplication by 2/3, multiply both sides by the reciprocal, 3/2:
- x = 10 × (3/2)
- x = **15**

**Check:** (2/3)(15) = 10. ✓

**Alternative:** Think of (2/3)x = 10 as x divided by 3 then multiplied by 2. Undo these operations in reverse order: divide by 2 first (x = 5 × 3 = 15). Same answer.

---

## Identifying the Right Operation

The key is to identify what operation is being done to the variable and then apply the inverse:

| What's happening to the variable | Inverse to apply |
| :--- | :--- |
| Adding a number | Subtract that number |
| Subtracting a number | Add that number |
| Multiplying by a number | Divide by that number |
| Dividing by a number | Multiply by that number |

Addition and subtraction undo each other. Multiplication and division undo each other. These pairs are called **inverse operations**.

## Word Problems: Setting Up One-Step Equations

**Example:** "A number decreased by 14 equals 38. What is the number?"
- "decreased by 14" → subtraction: n - 14 = 38
- Add 14 to both sides: n = **52**

**Example:** "Three times a number equals 75. Find the number."
- 3n = 75
- Divide by 3: n = **25**

**Example:** "After spending $47, Maria has $130 left. How much did she start with?"
- Let s = starting amount. s - 47 = 130.
- Add 47: s = **$177**

**Example:** "A car traveled 280 miles at a constant speed over 4 hours. How fast was it going?"
- Speed × time = distance: 4r = 280.
- Divide by 4: r = **70 mph**

---

## Common Mistakes

**Mistake 1:** Performing the operation on only one side.
- x + 5 = 12. Wrong: x = 12 - 5 (without noting you subtracted from both sides). Always write the step explicitly.

**Mistake 2:** Choosing the wrong inverse.
- x - 8 = 15. If you subtract 8 from both sides instead of adding, you get x - 16 = 7, which is wrong.

**Mistake 3:** Sign errors with negative coefficients.
- -x = -6 means x = 6 (dividing both sides by -1 changes both signs).

**Habit to build:** Always check by substituting your answer back into the original equation. If it makes the equation true, you're done.

5. -4p = 36
