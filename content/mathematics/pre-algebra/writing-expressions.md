## Writing and Evaluating Expressions

An algebraic expression is a combination of numbers, variables, and operations. It doesn't have an equals sign — it doesn't make a statement that something is true or false, it just describes a quantity. Knowing how to write and evaluate expressions is the foundation of algebra: it's the step between translating a real situation into math and actually solving it.

---

## Parts of an Expression

**Term:** A single number, variable, or product of numbers and variables.
- 5x is a term
- -3 is a term
- 7ab is a term

**Expression:** A combination of terms connected by addition or subtraction.
- 3x + 5 has two terms
- 4x² - 2x + 7 has three terms

**Coefficient:** The number multiplying a variable in a term.
- In 7x, the coefficient is 7
- In -3y, the coefficient is -3
- In x (written alone), the coefficient is 1 (invisible but present: 1x = x)

**Constant term:** A term with no variable — a plain number.
- In 4x + 9, the constant term is 9

**Like terms:** Terms that have the same variable raised to the same power. Only like terms can be combined.
- 3x and 7x are like terms
- 5x² and 2x are NOT like terms (different powers of x)
- 4x and 4y are NOT like terms (different variables)

---

## Combining Like Terms

To simplify an expression, combine like terms by adding or subtracting their coefficients.

**Example:** 3x + 5 + 2x - 1
- Like terms: 3x and 2x → 5x
- Constant terms: 5 and -1 → 4
- Simplified: **5x + 4**

**Example:** 4a² - 3a + 2 + a² + 5a - 7
- a² terms: 4a² + a² = 5a²
- a terms: -3a + 5a = 2a
- Constants: 2 - 7 = -5
- Simplified: **5a² + 2a - 5**

The expression is simplified but not solved — there's no equation here, just a shorter form of the same quantity.

---

## The Distributive Property

The distributive property lets you expand (or factor) expressions involving parentheses:

```
a(b + c) = ab + ac
a(b - c) = ab - ac
```

**Example:** 3(x + 4)
- 3 × x + 3 × 4 = **3x + 12**

**Example:** -2(5 - 3y)
- -2 × 5 + (-2) × (-3y) = -10 + 6y = **6y - 10**

The distributive property is one of the most-used tools in algebra. Any time you see a number pressed up against parentheses with no operation sign, that's multiplication, and the distributive property applies.

**Distributing a negative:** Be careful. Distributing -1(x - 4) gives -x + 4, not -x - 4. The negative applies to every term inside.

## Writing Expressions from Words

Translating language into algebra is a skill that requires practice. Here are the key patterns:

| Words | Operation | Expression |
| :--- | :--- | :--- |
| the sum of x and 9 | + | x + 9 |
| 6 more than n | + | n + 6 |
| a number decreased by 4 | - | n - 4 |
| 8 less than x | - | x - 8 |
| the product of 5 and y | × | 5y |
| twice a number | × | 2n |
| a number divided by 3 | ÷ | n/3 |
| three-fourths of n | × | (3/4)n |

**"Less than" reversal:** "8 less than x" is x - 8, NOT 8 - x. The base value (x) comes first.

**Grouping matters:** "Three times the sum of a number and 5" means 3(n + 5), not 3n + 5. The "sum of a number and 5" must be grouped first.

**Step-by-step translation:**
- "Five more than twice a number"
- "twice a number" → 2n
- "five more than" → + 5
- Expression: **2n + 5**

- "The quotient of a number and six, minus four"
- "quotient of a number and six" → n/6
- "minus four" → - 4
- Expression: **n/6 - 4**

## Evaluating Expressions

To evaluate an expression, substitute the given value for each variable, then simplify using order of operations.

**Critical habit:** Write parentheses around the substituted value. This prevents sign errors.

**Example:** Evaluate 4x - 3 when x = -2.
- Substitute: 4(-2) - 3
- Calculate: -8 - 3 = **-11**

**Example:** Evaluate 2a² - 5b when a = 3 and b = -1.
- Substitute: 2(3)² - 5(-1)
- Exponent first: 2(9) - 5(-1)
- Multiply: 18 + 5
- Result: **23**

**Example:** Evaluate (x + y)/z when x = 7, y = 3, z = 2.
- Substitute: (7 + 3)/2
- Numerator first: 10/2
- Result: **5**

---

## Common Mistakes

**Mistake 1:** Forgetting that 3x means 3 times x. Writing "3x + 2x = 3 + 2 = 5" instead of "5x."

**Mistake 2:** Combining unlike terms. 3x + 4y ≠ 7xy. These cannot be combined because x and y are different variables.

**Mistake 3:** Sign errors when distributing a negative.
- -(2x - 5) = -2x + 5, NOT -2x - 5.

**Mistake 4:** Squaring only part of an expression. If x = -3, then x² = (-3)² = 9, not -9. The negative is inside the square.

## Real-World Expression Writing

**Example:** A plumber charges $85 for a service call plus $65 per hour. Write an expression for the total charge after h hours.
- Total = 85 + 65h

**Example:** A store sells a product for p dollars and offers a 15% discount. Write an expression for the sale price.
- Sale price = p - 0.15p = 0.85p

**Example:** A rectangle has a length that is 3 more than twice its width. If the width is w, write expressions for the length and the perimeter.
- Length = 2w + 3
- Perimeter = 2(length) + 2(width) = 2(2w + 3) + 2w = 4w + 6 + 2w = **6w + 6**

## Practice

1. Simplify: 6x - 2 + 4x + 9
2. Expand: 5(2x - 3)
3. Write an expression: "The sum of a number and 12, multiplied by 4."
4. Evaluate 3x² - 2x + 1 when x = -2.
5. A rectangular yard has width w. The length is 5 feet more than three times the width. Write an expression for the perimeter.

**Answers:**
1. **10x + 7**
2. **10x - 15**
3. **4(n + 12)** or equivalently 4n + 48
4. 3(-2)² - 2(-2) + 1 = 3(4) + 4 + 1 = 12 + 4 + 1 = **17**
5. Length = 3w + 5; Perimeter = 2(3w + 5) + 2w = 6w + 10 + 2w = **8w + 10**
