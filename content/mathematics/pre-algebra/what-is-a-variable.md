## What Is a Variable?

A variable is a symbol — usually a letter — that represents a quantity that can change or that we don't yet know. Variables are what allow mathematics to move from "calculating specific answers" to "describing relationships in general." This is the step from arithmetic into algebra, and it is one of the most powerful conceptual leaps in all of mathematics.

---

## The Core Idea

In arithmetic, you work with specific numbers: 3 + 4 = 7.

In algebra, you work with unknowns and relationships: x + 4 = 7. What is x? Clearly x = 3. But now you have a tool that works for any version of this situation. If x + 4 = 15, then x = 11. If x + 4 = 100, then x = 96.

The variable x is not a specific number — it is a *placeholder* for whatever number makes the statement true.

Variables also express general relationships. The area of a rectangle is length times width — always, for any rectangle. Written with variables: A = l × w. This one formula describes infinitely many specific situations.

---

## Why Letters?

By convention, mathematicians use letters from the alphabet (especially x, y, z, n, a, b, c) as variables. The letter itself doesn't matter — it's just a label. You could use any symbol. The choice is often meaningful:
- x and y often represent unknown or general quantities
- n often represents a whole number (an "integer")
- r often represents a rate or radius
- t often represents time
- A, P, V often represent area, perimeter, volume

When reading someone else's algebra, check whether they define their variables explicitly. When writing your own, always define what your variables mean.

---

## Variables as Unknowns

In an equation, a variable represents a specific unknown value that we want to find.

- "A number plus 7 equals 15." → x + 7 = 15. Here x = 8.
- "Twice a number minus 3 equals 11." → 2n - 3 = 11. Here n = 7.

Solving the equation means finding the value of the variable that makes the statement true.

---

## Variables as Changing Quantities

In a formula or relationship, a variable doesn't represent one fixed unknown — it represents any value from a possible range. The formula changes as the variable changes.

**Example:** The total cost of renting a car is $30 per day. If d represents the number of days:
- Cost = 30 × d, or C = 30d

When d = 1, C = 30. When d = 5, C = 150. When d = 10, C = 300.

The variable d can be any number of days. The formula describes the relationship for all possible values.

**Example:** Perimeter of a square with side length s:
- P = 4s

This works for a square with side 2 (P = 8), side 7 (P = 28), or side 100 (P = 400).

## Reading Algebraic Expressions

Variables and numbers are combined using operations to form expressions.

| Expression | Meaning |
| :--- | :--- |
| x + 5 | five more than x |
| 3n | three times n (multiplication is implied by adjacency) |
| y - 4 | four less than y |
| m/6 | m divided by 6 |
| 2x + 1 | twice x, plus one |

**Note on notation:** In algebra, the multiplication sign × is avoided because it looks like the variable x. Instead, multiplication is shown by:
- Placing a number directly next to a variable: 3n means 3 × n
- Using parentheses: 3(n + 2) means 3 × (n + 2)
- Using a dot: 3·n

---

## Translating Words into Expressions

This is where algebra meets real problems. You read a word description and write the corresponding expression with variables.

**Key phrases:**
- "a number" → use a variable, often x or n
- "sum of" → addition
- "difference of" → subtraction
- "product of" → multiplication
- "quotient of" → division
- "twice" → × 2
- "more than" → +
- "less than" → -
- "is" → =

**Examples:**
- "Seven more than a number" → n + 7
- "Four times a number, decreased by 9" → 4n - 9
- "The quotient of a number and 5" → n/5
- "Three less than twice a number" → 2n - 3

**Watch the order:** "5 less than x" means x - 5, not 5 - x. The phrase "less than" reverses the expected order.

---

## Evaluating Expressions

To **evaluate** an expression means to substitute a specific value for the variable and calculate the result.

**Example:** Evaluate 3x + 2 when x = 4.
- Substitute: 3(4) + 2
- Calculate: 12 + 2 = **14**

**Example:** Evaluate 2a - b + 5 when a = 3 and b = 7.
- Substitute: 2(3) - 7 + 5
- Calculate: 6 - 7 + 5 = **4**

When evaluating, always substitute the value with parentheses to avoid sign errors: write 3(-2) not 3-2.

---

## Constants vs. Variables

A **constant** is a fixed value that doesn't change. In the formula C = 30d, the 30 is a constant — it's the daily rate and doesn't vary. The d is the variable — it changes depending on how many days you rent.

In the expression 5x + 3:
- x is the variable
- 5 (the coefficient of x) and 3 (the constant term) are both constants

Understanding this distinction matters because when you solve equations, you move constants to one side and variables to the other.

## Practice

1. Write an expression for "eight less than three times a number."
2. Evaluate 5n - 4 when n = 6.
3. Evaluate x² + 2x - 1 when x = 3.
4. A plumber charges a $75 flat fee plus $50 per hour. Write a formula for the total charge C in terms of hours h.
5. Using your formula from #4, find the total charge for a 4-hour job.

**Answers:**
1. 3n - 8
2. 5(6) - 4 = 30 - 4 = **26**
3. 9 + 6 - 1 = **14**
4. C = 75 + 50h
5. C = 75 + 50(4) = 75 + 200 = **$275**
