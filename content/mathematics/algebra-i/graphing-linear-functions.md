## Graphing Linear Functions

A linear function produces a straight line when graphed on the coordinate plane. The graph reveals the behavior of the function at a glance — its direction, steepness, starting point, and where it crosses the axes. Being able to graph from an equation and read an equation from a graph are both essential skills, and they're used together constantly in data analysis, business modeling, and science.

---

## The Slope-Intercept Method

The most direct way to graph y = mx + b:

1. Plot the **y-intercept** (0, b) — the point where the line crosses the y-axis.
2. Use the **slope** m = rise/run to find a second point: from the y-intercept, move right by the "run" and up (or down) by the "rise."
3. Draw a line through both points.

**Example:** Graph y = 2x + 1

- Y-intercept: b = 1 → plot (0, 1)
- Slope: m = 2 = 2/1 → from (0, 1) move right 1, up 2 → plot (1, 3)
- Draw the line through (0, 1) and (1, 3)

You can check with a third point: x = 2 → y = 2(2) + 1 = 5 → (2, 5) should be on the line.

**Example:** Graph y = -3/4 x + 3

- Y-intercept: (0, 3)
- Slope: m = -3/4 → from (0, 3) move right 4, down 3 → plot (4, 0)
- Line falls from left to right (negative slope)

## The Table of Values Method

Generate a set of (x, y) pairs by plugging in x values, then plot.

**Example:** y = -x + 4

| x | y = -x + 4 | Point |
| :--- | :--- | :--- |
| -2 | 6 | (-2, 6) |
| 0 | 4 | (0, 4) |
| 2 | 2 | (2, 2) |
| 4 | 0 | (4, 0) |

Plot these four points and draw the line. The table method is slower but gives you confidence when verifying your graph.

## Finding X and Y Intercepts

The **x-intercept** is where the line crosses the x-axis — where y = 0.
The **y-intercept** is where the line crosses the y-axis — where x = 0.

These two points alone are enough to graph any non-vertical, non-horizontal line.

**Example:** Graph 2x + 3y = 12 using intercepts.

X-intercept (set y = 0): 2x = 12 → x = 6 → point (6, 0)
Y-intercept (set x = 0): 3y = 12 → y = 4 → point (0, 4)

Draw the line through (6, 0) and (0, 4).

---

## Graphing Horizontal and Vertical Lines

**Horizontal line y = k:** A constant function. For any x, y equals the same value k. The graph is a flat horizontal line.
- y = -2: a horizontal line through every point with y = -2.
- Slope = 0.

**Vertical line x = k:** Not a function, but a line. For any y, x equals the same value k.
- x = 3: a vertical line through every point with x = 3.
- Slope = undefined.

## Reading a Graph to Write an Equation

Given a graph, you can extract the equation:

**Step 1:** Identify the y-intercept (where the line crosses the y-axis). This is b.

**Step 2:** Find the slope. Pick two clear points on the line. Calculate rise/run.

**Step 3:** Write y = mx + b.

**Example:** A line crosses the y-axis at (0, -2) and passes through (4, 6).
- b = -2
- m = (6 - (-2))/(4 - 0) = 8/4 = 2
- Equation: **y = 2x - 2**

## Interpreting Linear Graphs in Context

A graph always tells a story. You must be able to interpret what each feature means.

**Example:** A graph shows a plumber's total charge versus hours worked. The line passes through (0, 85) and (3, 275).
- Y-intercept (0, 85): The flat fee before any work is done — $85 service call charge.
- Slope = (275 - 85)/(3 - 0) = 190/3 ≈ 63.3: approximately **$63.33 per hour**.
- Equation: C = 63.3h + 85 (approximately)

**Reading a specific value:** "How much for a 5-hour job?" On the graph, find x = 5 and read the y-value. Algebraically: C = 63.3(5) + 85 = $401.50.

## Graphing from Real-World Relationships

**Example:** A car has 14 gallons of gas and uses 0.04 gallons per mile. Write and graph the function for gas remaining after m miles.

- G(m) = 14 - 0.04m
- Y-intercept: (0, 14) — starts with 14 gallons
- X-intercept: 0 = 14 - 0.04m → 0.04m = 14 → m = 350. The car runs out at 350 miles.
- Slope: -0.04 — loses 0.04 gallons per mile

This graph goes from (0, 14) down to (350, 0) — a line with negative slope showing fuel decreasing.

---

## Key Features of Linear Graphs Summary

| Feature | What it tells you |
| :--- | :--- |
| Y-intercept | Starting value (at x = 0) |
| X-intercept | Where the output reaches zero |
| Positive slope | Output increases as x increases |
| Negative slope | Output decreases as x increases |
| Steeper slope | Faster rate of change |
| Flatter slope | Slower rate of change |
| Slope = 0 | No change — constant output |

## Practice

1. Graph y = -2x + 6 using the slope-intercept method.
2. Graph 4x - 2y = 8 using x and y intercepts.
3. A line has slope 3/4 and y-intercept -2. Write the equation and describe the line's direction.
4. A line passes through (1, 5) and (4, -4). Find the equation and graph it.
5. A savings account starts at $500 and grows by $50 per month. Write the function and identify the slope and y-intercept in context.

**Answers:**
1. Y-intercept: (0, 6); slope -2: from (0, 6), right 1, down 2 → (1, 4). Line falls left to right.
2. X-intercept: set y=0: 4x = 8 → (2, 0). Y-intercept: set x=0: -2y = 8 → y = -4 → (0, -4). Line through those two points.
3. **y = 3/4 x - 2**; slope is positive so line rises left to right (though not steeply).
4. m = (-4 - 5)/(4 - 1) = -9/3 = -3; y - 5 = -3(x - 1) → y = -3x + 8. **y = -3x + 8**
5. S(m) = 50m + 500. Slope 50 = adds $50/month; y-intercept 500 = initial balance.
