Chemistry has its own language for naming compounds, and learning to speak it — and translate it back into formulas — is an essential skill. Systematic nomenclature (the naming rules) ensures that any chemist anywhere in the world can unambiguously communicate what substance they're working with. The rules differ by compound type: ionic compounds, covalent compounds, and acids each follow their own conventions.

---

## 1. Ionic Compounds: Binary (Two Elements)

Binary ionic compounds contain a metal cation and a non-metal anion.

**Rule:** Name the **cation** first (use the element name unchanged), then the **anion** (change the non-metal's name to end in **-ide**).

| Formula | Cation name | Anion name | Compound name |
|---------|------------|-----------|---------------|
| NaCl | sodium | chloride | sodium chloride |
| MgO | magnesium | oxide | magnesium oxide |
| CaBr₂ | calcium | bromide | calcium bromide |
| Li₂S | lithium | sulfide | lithium sulfide |
| AlN | aluminum | nitride | aluminum nitride |
| K₃P | potassium | phosphide | potassium phosphide |

Non-metal anion name changes:
- Fluorine → fluoride
- Chlorine → chloride
- Bromine → bromide
- Iodine → iodide
- Oxygen → oxide
- Sulfur → sulfide
- Nitrogen → nitride
- Phosphorus → phosphide

---

## 2. Transition Metal Cations (Stock System)

Transition metals (and a few others like Pb, Sn) can form cations with different charges. The charge is indicated with a **Roman numeral in parentheses** immediately after the element name — the **Stock system**.

| Formula | Name |
|---------|------|
| FeCl₂ | iron(II) chloride (Fe is +2, so 2 Cl⁻ needed) |
| FeCl₃ | iron(III) chloride (Fe is +3, so 3 Cl⁻ needed) |
| CuO | copper(II) oxide |
| Cu₂O | copper(I) oxide |
| SnF₂ | tin(II) fluoride |
| PbO₂ | lead(IV) oxide |

To determine the charge on the metal: the total positive charge must balance the total negative charge. In FeCl₃, 3 Cl⁻ = −3, so Fe must be +3.

---

## 3. Ionic Compounds with Polyatomic Ions

Polyatomic ion names are memorized — they don't change when used in compound names:

**Common polyatomic ions:**
- NO₃⁻ = nitrate
- NO₂⁻ = nitrite
- SO₄²⁻ = sulfate
- SO₃²⁻ = sulfite
- PO₄³⁻ = phosphate
- CO₃²⁻ = carbonate
- HCO₃⁻ = bicarbonate (or hydrogen carbonate)
- OH⁻ = hydroxide
- CN⁻ = cyanide
- NH₄⁺ = ammonium
- ClO₃⁻ = chlorate
- ClO₄⁻ = perchlorate
- MnO₄⁻ = permanganate
- Cr₂O₇²⁻ = dichromate
- C₂H₃O₂⁻ = acetate

**Examples:**
- Ca(NO₃)₂: calcium nitrate
- K₂SO₄: potassium sulfate
- NH₄Cl: ammonium chloride
- Fe₂(SO₄)₃: iron(III) sulfate
- Mg(OH)₂: magnesium hydroxide

**Pattern for -ate / -ite:** The ion ending in *-ate* has more oxygen; the one ending in *-ite* has fewer. (Sulfate SO₄²⁻ has 4 O; sulfite SO₃²⁻ has 3 O.)

## 4. Covalent (Molecular) Compounds: Binary

Binary covalent compounds are made of two non-metals. They use **Greek prefixes** to indicate the number of each atom:

| Number | Prefix |
|--------|--------|
| 1 | mono- |
| 2 | di- |
| 3 | tri- |
| 4 | tetra- |
| 5 | penta- |
| 6 | hexa- |
| 7 | hepta- |
| 8 | octa- |
| 9 | nona- |
| 10 | deca- |

**Rules:**
1. The **first** element in the formula is named with its element name (mono- is omitted for the first element if there's only one)
2. The **second** element is named with an -ide ending and always has a prefix
3. If the prefix ends in *a* or *o* and the element name starts with a vowel, drop the trailing vowel (monoxide, not monooxide; tetroxide, not tetraoxide)

**Examples:**
- CO: carbon monoxide (not monooxide)
- CO₂: carbon dioxide
- NO₂: nitrogen dioxide
- N₂O₄: dinitrogen tetroxide
- SF₆: sulfur hexafluoride
- PCl₃: phosphorus trichloride
- PCl₅: phosphorus pentachloride
- N₂O: dinitrogen monoxide (laughing gas)
- CCl₄: carbon tetrachloride

**Note:** Do NOT use prefixes for ionic compounds. "Disodium oxide" is wrong; it's "sodium oxide" (the ratio is determined by the charges, not chosen).

## 5. Naming Acids

Acids are identified by the presence of H⁺ donors in aqueous solution. Naming rules depend on whether the acid contains oxygen.

### Binary Acids (no oxygen; in aqueous solution)

The non-oxygen anion is named with a **hydro-** prefix and an **-ic acid** suffix:

| Formula | Anion | Acid name |
|---------|-------|-----------|
| HF(aq) | F⁻ (fluoride) | hydrofluoric acid |
| HCl(aq) | Cl⁻ (chloride) | hydrochloric acid |
| HBr(aq) | Br⁻ (bromide) | hydrobromic acid |
| HI(aq) | I⁻ (iodide) | hydroiodic acid |
| H₂S(aq) | S²⁻ (sulfide) | hydrosulfuric acid |

(HF as a pure gas is just "hydrogen fluoride"; as an aqueous solution it's "hydrofluoric acid.")

### Oxyacids (contain oxygen)

The name is derived from the polyatomic anion:

- **-ate** anion → **-ic acid**
- **-ite** anion → **-ous acid**

| Anion | Anion name | Acid | Acid name |
|-------|-----------|------|-----------|
| NO₃⁻ | nitrate | HNO₃ | nitric acid |
| NO₂⁻ | nitrite | HNO₂ | nitrous acid |
| SO₄²⁻ | sulfate | H₂SO₄ | sulfuric acid |
| SO₃²⁻ | sulfite | H₂SO₃ | sulfurous acid |
| PO₄³⁻ | phosphate | H₃PO₄ | phosphoric acid |
| CO₃²⁻ | carbonate | H₂CO₃ | carbonic acid |
| ClO₄⁻ | perchlorate | HClO₄ | perchloric acid |
| ClO₃⁻ | chlorate | HClO₃ | chloric acid |

## 6. Writing Formulas from Names

The reverse process: given a name, write the correct formula.

1. **Binary ionic**: identify ions, determine charges, balance charges to zero
   - Calcium bromide: Ca²⁺ and Br⁻ → CaBr₂
   - Aluminum oxide: Al³⁺ and O²⁻ → Al₂O₃ (criss-cross magnitudes)

2. **Transition metal ionic**: Roman numeral gives the cation charge
   - Iron(III) chloride: Fe³⁺ and Cl⁻ → FeCl₃

3. **Polyatomic ionic**: use the polyatomic ion formula directly
   - Ammonium sulfate: NH₄⁺ and SO₄²⁻ → (NH₄)₂SO₄

4. **Covalent**: prefixes give atom counts
   - Dinitrogen pentoxide: N₂O₅

5. **Acids**: reverse the naming convention
   - Nitrous acid → -ous → -ite → NO₂⁻ → HNO₂

---

## Summary

Ionic compound names: cation first (unchanged for fixed-charge metals; with Roman numeral for variable-charge metals) + anion with -ide, or polyatomic ion name. Covalent compound names: Greek prefixes indicate atom counts; second element ends in -ide. Binary acid names: hydro- + anion root + -ic acid. Oxyacid names: derived from the polyatomic anion (-ate → -ic acid; -ite → -ous acid). In all cases, the name unambiguously specifies the formula, and the formula specifies the name.
