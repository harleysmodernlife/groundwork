# Groundwork Roadmap

This is a living document. It will change as the project grows.

The mission does not change: free education for everyone, no asterisks, forever.

---

## Phase 1 — Foundation ✓

Get a single subject working end-to-end. Prove the model. Ship something real.

- [x] Project scaffold (Next.js, Prisma, Auth.js, Vercel AI SDK)
- [x] Database schema (users, curriculum, assessments, certificates, AI conversations)
- [x] AI provider routing (free tier + BYOK)
- [x] Certificate generation (Open Badges 3.0)
- [x] API routes (auth, progress, assessment, AI tutor, platform help)
- [x] Auth UI (signup, login)
- [x] Lesson player (MDX rendering, progress tracking)
- [x] AI tutor panel (Socratic, in-lesson)
- [x] Exercise system (multiple choice + AI-graded open-ended)
- [x] Assessment system (timed, scored, pass/fail)
- [x] Certificate verification page (public, employer-readable)
- [x] Groundwork Assistant (platform help widget, BYOK walkthrough)
- [x] Docker Compose deployment

**Done.**

## Phase 3 — Public Launch (Current)

Open the doors. Get real learners. Prove the certificate means something.

- [ ] End-to-end testing and bug fixes
- [ ] Mobile-responsive polish
- [ ] Accessibility audit (WCAG 2.1 AA)
- [ ] Production deployment
- [ ] Public beta — first real learners

**Target:** First learner earns a real certificate

---

## Phase 4 — Employer Marketplace

Make the certificate worth something in the real world.

- [ ] Paid employer subscriptions
- [ ] First employer partnership
- [ ] Employer analytics (hiring outcomes, top certifications)
- [ ] Verification API (employers verify a certificate programmatically)

**This is the revenue engine. Students never pay. Employers pay to recruit.**

---

## Phase 5 — Scale

Make it work for the world, not just early adopters.

- [ ] Internationalization (i18n) — Spanish, French, Portuguese, Hindi, Arabic first
- [ ] Offline support (service workers, downloadable lesson packs)
- [ ] Community forums (per-subject discussion, peer study)
- [ ] Mentorship matching (graduates mentoring new learners)
- [ ] API for institutions (schools and nonprofits can embed Groundwork)
- [ ] Mobile apps (iOS and Android)
- [ ] Government and NGO partnerships

---

## Phase 6 — The Long Game

Where it goes if we do everything right.

- [ ] Every major academic subject covered
- [ ] Recognized by employers in every industry
- [ ] Localized for every major language
- [ ] Self-sustaining financially with zero cost to students, ever
- [ ] Open curriculum standard — Groundwork courses portable to any platform
- [ ] 1 million learners

---

## What We Will Never Do

- Charge students for courses
- Charge students for certificates
- Charge students for AI tutoring (free tier always exists)
- Sell student data
- Take venture capital that requires an exit
- Paywall anything that is currently free

These are not aspirations. They are constraints built into the legal structure of the organization.
